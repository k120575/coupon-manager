Android Studio 操作步驟

步驟 1：下載 Foreground PNG

上面點「下載 Foreground PNG」，存到桌面，得到 coupy_foreground_432.png。

步驟 2：開 Image Asset Studio

  1. Android Studio 左側 Project 視窗，右鍵點 app/src/main/res
  2. 選 New → Image Asset
  3. Icon Type 選 Launcher Icons (Adaptive and Legacy)

步驟 3：Foreground Layer 設定

  1. Layer 切到 Foreground Layer
  2. Source Asset 選 Image
  3. Path 選剛剛下載的 coupy_foreground_432.png
  4. Trim 不勾、Resize 留 100%（圖已經做好邊距）

步驟 4：Background Layer 設定

  1. Layer 切到 Background Layer
  2. Asset Type 選 Color
  3. 顏色填 #0F0F0F

步驟 5：產出

  1. 下方 Output Directory 確認指向 app/src/main/res
  2. 按 Next → Finish（會問要不要覆蓋，按 OK）
  3. 它會自動產出 5 個 density 的 webp + adaptive icon xml

步驟 6：刪掉舊的暫用版本

之前手刻的 vector drawable 可以刪了：

  1. 刪 app/src/main/res/drawable/ic_launcher_foreground.xml（如果 Image Asset 沒自動覆蓋）
  2. 確認 mipmap-anydpi-v26/ic_launcher.xml 用新生成的版本

步驟 7：Play Store 上架素材

上面下載 coupy_play_store_512.png，上架時上傳到 Play Console 的 App icon 欄位（不放專案內、不進 git）。

步驟 8：跑一次 App 確認

Run 一次，看桌面 icon、最近 App 列表的圖示有換成新的。
